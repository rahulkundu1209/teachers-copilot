Inside the root folder keep agents(folder), requirements.txt and .env
1. agents(folder): All the ai-agent files(.py) and langgraph.json file
2. .env and requirements.txt content as given.

Create Virtual Environment(cmd) -
> python -m venv venv
Activate Virtual Environment(cmd) -
> venv\Scripts\activate
Install dependencies:
> pip install -r requirements.txt
Run the agents:
Inside the agents folder, run -
> langgraph dev
